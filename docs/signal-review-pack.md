## 2. 信号生成规则（伪代码）

```
背景 1h：摆动结构（swing=8）最近一次 BOS/CHoCH 的方向；
          若已被反向收盘破坏 → range
方向 15m：摆动结构（swing=8）的 trendAtEnd，且该突破发生在当前北京日内；
          位移硬过滤：定方向的突破 K 线范围 ≥ 1.5 × ATR(200)
区域 15m：未缓解的同向 OB 与 FVG，且区域内有位移；
          价格进入区域 ±0.15 × ATR 视为入区
确认1：入区后，15m 内部结构（internal=4）同向 BOS/CHoCH
确认2：入区后，5m 同向结构突破 / 吞没 / Pin Bar
配对：确认1 与确认2 的首次事件间隔 ≤ 30 分钟（6 根 5m）
去重：同一区域只推一次；区域在 6h 到期、15m 收盘越过远端、或 15m 方向翻转时失效
风控：入场 = 区域近端；止损 = 区域远端 ∓ 0.2 × ATR；
      止盈 = 最近对手流动性（1h 摆动点、前日高低、上一个亚洲盘高低、当前盘前 30 分钟高低），
      优先取 RR ≥ 2 的最近一个，否则取最近；无目标则不出信号
推送：仅通知，不含下单
```

过滤优先级：方向（1h 偏置 + 15m 当天方向 + 位移）→ 区域（未缓解、顺方向、位移）→ 确认配对 → 去重 → 止盈目标存在。
