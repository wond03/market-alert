# 模块：看盘页（market-dashboard/index.html）

单文件静态网页（内联 CSS + JS），零构建，托管在 GitHub Pages。图表使用 CDN 引入的 `lightweight-charts`。

## 结构

- **工具条**：图表周期切换、指标注册表 `IND`（当前仅「交易时段」时段框叠加）、价格 / 对数刻度、定位到最新。
- **主图**：K 线 + 叠加层。
  - `sessions-overlay`：交易时段框。
  - `smc-fill` / `smc-tag` / `smc-info`：BOS / CHoCH、OB、FVG、扫荡的可视化。
- **作战面板弹窗**：`btnBattle` 打开，包含刷新、HTF/MTF 周期选择、结果表与显示精度控制。渲染逻辑：`renderBattle`（读数）、`renderBattleSignals`（信号）、`renderBattleOutcomes`（了结）、`wireBattleUI`、`refreshBattleRecords`。

## 数据获取

- 通过适配器 `INSTRUMENTS` 支持多数据源：
  - **Gate**（主）：WebSocket `wss://fx-ws.gateio.ws/v4/ws/usdt`，实时增量更新，`maxBars` 约 400。
  - WEEX：`https://api-contract.weex.com/capi/v3/market/klines`。
  - OKX：`https://www.okx.com/api/v5/market/candles`。
- 品种仅 BTC / XAU；WebSocket 订阅 / 退订通过 `{op:"subscribe"|"unsubscribe"}`。

## 与后端交互

- `CONVEX_URL` 指向 prod：`https://efficient-cod-911.convex.cloud`。
- 通用 `fetch(CONVEX_URL + "/api/" + kind)` 封装：`convexQuery` / `convexAction`，一次性 HTTP 拉取（非订阅）。
- 调用：
  - `panel:analyze` — 主图结构分析。
  - `panel:battleStatus` — 作战面板读数。
  - `battle:recentBattleSignals`、`battle:recentBattleOutcomes` — 历史信号与了结。
- 计算全部下沉到 Convex `panel:*`，前端只负责绘制，避免与后端判定漂移。
