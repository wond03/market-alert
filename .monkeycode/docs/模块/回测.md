# 模块：回测（backtest/）

离线回测用于验收作战面板口径，不属于生产链路。

## 文件

| 文件 | 职责 |
| --- | --- |
| `history.ts` | 从 Gate 分页拉取历史 K 线并本地缓存 |
| `battle.ts` | 重放历史，复用生产 `evaluateBattle` 复算指标 |

## history.ts

- `fetchHistory(contract, interval, maxPoints)`：按区间分页拉取，归一化（`Number` 转换、按 `t` 排序、仅保留已收盘 K 线），写入本地 `.cache` 目录。
- `SEC` 映射周期到秒；失败返回空。
- 合约形如 `BTC_USDT`，周期如 `1m|5m|15m|...`。

## battle.ts

- 直接复用生产纯逻辑：

```ts
import { evaluateBattle, MTF, LTF, type BattleState } from "../convex/battleCore";
import { contractOf } from "../convex/exchanges";
import { fetchHistory, type Candle } from "./history";
```

- 参数：`CONFIGS[]`（区域窗口 `windowSec` × 确认间距 `span` 的组合）+ BTC / XAU 两个标的；前向 24h、往返成本 10 bps。
- 逐根 5m K 调用 `evaluateBattle`，维护每配置的 `BattleState`；了结规则为：多单收盘 ≥ 止盈 → 盈、触及止损 → `-1`，止损优先；空单反向。
- `summarize()` 输出每组 `n`、`wins`、`losses`、胜率、毛 / 净 R、期望值，并打印参数敏感性网格（窗口 8/12/24 × 间距 3/6/9）。

## 运行

```bash
npx tsx backtest/battle.ts
```

（暂无对应 npm script；配置与区间写死在脚本内。）

## 已知限制

- 历史区间与交易笔数有限（约 31 天 / 21 笔），统计口径为小样本。
- 受 Gate 5m 历史深度限制。
