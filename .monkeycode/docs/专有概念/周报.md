# 周报（report）

周报是系统的复盘链路：每周一汇总近 7 天的作战面板信号，输出指标与归因结论并推送到 Telegram。

实现位于 `convex/report.ts`，由 cron `signal weekly report` 触发 `weeklyReport`。

## 数据来源

- `reportData`（internalQuery）读取 `battleSignals` 中 `sigTs >= since` 的记录。
- `since` = 当日（北京）零点往前推 6 天。
- `openedTs` 取全部信号的 `sigTs`；`closed` 仅取已了结（`result` 为 `stop` / `target` 且存在 `exitPrice` / `closedTs`）的记录。

## 指标口径

`metrics(list)` 计算：

| 指标 | 含义 |
| --- | --- |
| `n` | 交易笔数 |
| `wins` / `losses` | 盈 / 亏笔数 |
| `winRate` | 胜率 |
| `sumR` | 累计净 R |
| `sumPct` | 累计百分比收益 |
| `expR` | 每笔期望值（R/笔） |
| `mdd` | 最大回撤 |
| `maxLoss` | 最大连续亏损 |
| `avgHoldH` | 平均持仓小时 |

- 单笔 R：`tradeR(t)`，按止损距离归一。
- 单笔百分比：`tradePct(t)`。

## 归因维度

周报按以下维度分组统计，选出样本量 ≥ `MIN_N`（3）中最好 / 最差的分组，并附结论；样本量 < 10 时追加小样本提示：

- 方向（多 / 空）
- 触发类型（`confirm`）
- 区域类型（OB / FVG）

## 触发与开关

- 仅当 `BATTLE=1` 时执行，否则返回 `{skipped:true}`。
- 手动运行（生产）：

```bash
npx convex run report:weeklyReport --prod
```
